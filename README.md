# Rock Paper Scissors

A simple college project implementing Rock Paper Scissors with a responsive web interface and Java game logic.

## Features
- Player vs computer
- Random computer choice
- Win, lose and draw detection
- Score and round tracking
- New Game reset
- Responsive interface

## Run the web game
Open `index.html` in a browser.

## Java
The Java source is in `src/main/java/com/shree07/rockpaperscissor/` and contains the core game logic. Maven configuration is included in `pom.xml`.

## Technologies
HTML, CSS, JavaScript and Java.

## Rules
Rock beats Scissors. Scissors beats Paper. Paper beats Rock.
